SOURCE REQUIREMENTS

We are members of the Disney Studio Content Security Program

01

Data Source Requirements

We can use a 2K DCP (preferable format), a 2K ProRes (ProRes4444 recommended), or a DPX/TIFF sequence along with 5.1 or 2.0 WAVs.

If your deliverables are not a DCP, e.g. ProRes, DPX, TIFF, etc, then they should incorporate a SMPTE universal countdown leader and a 2-pop for sync purposes and SMPTE or ARIB bars so we can verify the video levels. Please make sure that the grading monitor is properly calibrated and displays the PLUGE area black levels correctly.

Please also provide the following info: colourspace and gamma the content was graded for (e.g., Rec.709 gamma 2.4), data range full/head (studio) and a SHA256 hash to verify the integrity of the deliverables.

We kindly ask to note that up to 5-10% of the image area may be cropped when projected; it depends on the projector mask shape/size and how a particular screen is set up – please observe the 10% “action safe” margin as per SMPTE RP218 when composing the image (also see SMPTE 195). Image size in our recorders is calibrated as per SMPTE 59.

02

Subtitle Possibilities

Subtitles can be supplied in D-cinema XML format in UTF-8 encoding. Our digital printing systems allow complete flexibility. Subtitles can be created in any language, font, colour or position within the frame (vertical/horizontal).
